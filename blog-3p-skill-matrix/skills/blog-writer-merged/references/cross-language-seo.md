# Cross-language editorial method

Use this method inside W’s research-and-writing loop when the frozen campaign targets another language or region.

1. Inspect current public brand pages for the same locale and intent. Record URL, context and date. This is the highest-priority wording source.
2. Use global Google Trends only with **English seed terms and English long-tail candidates**, regardless of the target language. Record English source concept/query, `GT seed language = ENGLISH_ONLY`, scope, time window, date and relative signal; do not treat it as local search volume or compare target-language variants in GT.
3. Inspect target-region SERPs to identify reader intent, natural phrasing and modifiers for the mapped English concept. Record query, date and semantic patterns; never copy competitors.
4. Select wording in strict order: `CURRENT_BRAND_SITE → REGIONAL_SERP → MODEL_TRANSLATION_FALLBACK`.
5. A fallback is permitted only after two independent regional-SERP checks document no usable consensus wording. Record both checks, source concept, proposed wording, language/intent rationale and cultural/legal risk. Never label it SERP-proven.

Freeze the English-concept-to-regional-SERP map in `research/cross-language-seo.md`; R independently judges its quality before G verifies that the frozen localization requirement is represented in final delivery.
